# ChaloChale 🌍✈️ 
ChaloChale is a fully responsive travel and tour booking website built using **HTML5 and Bootstrap 5**. The project provides a modern and mobile-friendly interface for exploring destinations, viewing tour packages, and connecting with travelers. --- 
## 🚀 Features 
- Responsive Bootstrap navbar 
- Hero section with carousel 
- Popular destinations section 
- Tour packages section 
- About Us page 
- Contact page 
- Login and Signup pages 
- Bootstrap cards, buttons, modal-forms, and grid system 
- Mobile-friendly design -
 Font Awesome icons integration --- 
 ## 🛠️ Technologies Used 
- **HTML5**
- **Bootstrap 5**
- **Font Awesome** 
- **Devin AI** (used for development assistance and project support)
